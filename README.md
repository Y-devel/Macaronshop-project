# Macaronshop

Адаптивная страница магазина десертов по приложенному макету.

## Структура

- `index.html` — разметка и основные секции страницы.
- `styles/main.css` — оформление, адаптивные стили и анимация градиента.
- `scripts/main.js` — каталог, буллиты, мобильное меню и интерактивная корзина.

## Запуск

Откройте `index.html` в браузере. Для разработки можно запустить локальный сервер, например `npx serve .`.

Google Fonts подключены через Manrope и Playfair Display. Изображения загружаются с Unsplash.
